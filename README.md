
# Python Learning & AI Agents

Repositorio de ejercicios y proyectos realizados durante mi aprendizaje de Python, APIs REST y agentes de inteligencia artificial.

## Contenido

- **01_fundamentos:** funciones, listas, diccionarios y strings.
- **02_poo:** programación orientada a objetos.
- **03_logica:** ejercicios de lógica y simulacros de entrevistas técnicas.
- **04_apis:** consumo de APIs REST y procesamiento de respuestas JSON.
- **05_agentes_ia:** integración de modelos LLM mediante Groq y ejercicios de selección de herramientas.

## Tecnologías

- Python 3.12
- Groq API
- Requests
- Python-dotenv

## Instalación

1. Clonar el repositorio.
2. Crear un entorno virtual.
3. Instalar las dependencias con `pip install -r requirements.txt`.
4. Copiar `.env.example` como `.env`.
5. Configurar `GROQ_API_KEY` en `.env`.

## Objetivo

Consolidar mis conocimientos de desarrollo backend, automatización e integración de herramientas de inteligencia artificial mediante ejercicios y proyectos prácticos.
